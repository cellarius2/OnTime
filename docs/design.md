# Design system notes

The current interface is the source of truth. Toolkit adoption must preserve its layout, colors, typography, spacing, motion, imagery and responsive behavior.

## Existing patterns
- Dark, rounded dashboard surfaces with green status and action accents.
- Separate chat and reminder panels on larger screens with responsive stacking on smaller screens.
- Compact tag, status and icon controls.
- Jonas character imagery and conversational feedback.

## Review criteria
- No horizontal overflow at common mobile widths.
- Controls remain keyboard reachable and retain visible focus.
- Text and status colors maintain readable contrast.
- Loading, error and disabled states remain distinguishable.
- Long reminder text wraps without overlap.

No visual tokens or components were changed during toolkit adoption.
